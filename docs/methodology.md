# Methodology
ICBHI cycle annotations contain start/end times and binary crackle/wheeze labels. The two outputs map to Normal (0,0), Crackles (1,0), Wheezes (0,1), and Both (1,1). Baseline features are MFCC means/stds and delta-MFCC summaries; models are Random Forest and SVM. An optional CNN uses log-Mel inputs and BCEWithLogitsLoss. GroupShuffleSplit groups by patient ID inferred from filename, with recording ID fallback. This fallback does not prove unseen-patient generalization. Quality warnings are heuristics. Highlighted windows show elevated model scores, not biological causes. Scores are not calibrated clinical probabilities.
